# Python Projects — From Beginner to Advanced

A growing collection of Python projects built to learn by doing. Every folder is a self-contained project with its own README, so you can read the code, run it, and understand *why* it is written that way — not just copy it.

If you are learning Python and tired of tutorials that stop at "hello world", start at the top of this list and work down.

## Projects

| Project | What it is | Level | Key concepts |
| --- | --- | --- | --- |
| [Tic-Tac-Toe](./Tic-Tac-Toe) | Tic-Tac-Toe with a GUI and an AI opponent | Advanced | Minimax / game AI, GUI, game loop |
| [Smart Calculator](./calculator) | Calculator that handles real expressions | Intermediate | Parsing, error handling, functions |
| [Contact Book](./contact-book) | Add, search and store contacts | Intermediate | CRUD, file persistence, data structures |
| [Password Strength Checker](./password-strength-checker) | Scores a password and explains why | Beginner | Strings, regex, conditionals |

## Getting started

```bash
git clone https://github.com/hammadarif-pk/Python-Projects.git
cd Python-Projects
```

Then open any project folder and follow its README:

```bash
cd Tic-Tac-Toe
python main.py
```

Requires Python 3.8 or newer. Most projects use only the standard library; if a project needs extra packages, its own README says so.

## Why this repo exists

Reading code teaches syntax. Building projects teaches judgement — how to structure a program, where bugs hide, and when a simpler solution is the better one. Each project here was chosen because it forces a specific skill: state management, input validation, algorithms, or user interface work.
